FAQ

What is UMA SEO AI?

UMA SEO AI is a free SEO agent that runs automatically every day on GitHub Actions.

What on-page SEO elements does UMA SEO AI audit?

It audits a website's title, meta description, headings, images, links, schema, robots.txt, and sitemap.

How does UMA SEO AI measure website speed?

It measures speed using Google PageSpeed Insights.

How does UMA SEO AI generate content and keyword ideas?

It finds keyword ideas from Google Autocomplete and uses Gemini AI to write articles, tags, and an action plan.

Can UMA SEO AI compare my site to competitors?

Yes, it compares your site with competitor websites on on-page SEO.

Does UMA SEO AI show competitor backlinks or search volume?

No, it does not show competitor search volume or backlinks because that data is paid.

How does UMA SEO AI protect my site if something breaks?

A monitor checks the site every hour and rolls the site back to the last working version if it breaks.

How often does UMA SEO AI run audits and checks?

It runs automated SEO audits every day on GitHub Actions and monitors the site every hour for uptime.
